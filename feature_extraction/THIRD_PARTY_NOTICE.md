# Third-party code and models

This pipeline uses the UMambaBot implementation and nnU-Net integration from the repository
`ToothFairy2-Benchmark` at the workspace root. The benchmark source is imported without modification.

The sliding-window inference and preprocessing behavior follows nnU-Net v2. Cite nnU-Net and the ToothFairy2
benchmark/publication when using generated results. Model weights and dataset files retain their original terms.
